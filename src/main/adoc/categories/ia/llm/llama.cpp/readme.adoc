= LLama.cpp

== Summary

> You  -->  Claude Code / VSCode Continue / etc  -->  llama-server (localhost:8131)  -->  Qwen 3.5-35B-A3B (GGUF on Metal)

== Setup

[source,bash]
----
# Prepare
$ brew update
$ brew upgrade

# Install
$ brew install llama.cpp
# Verify
$ llama-server --version

# Start the model Server
$ llama-server \
  -hf unsloth/Qwen3.5-35B-A3B-GGUF:Q4_K_M \
  --port 8131 \
  -ngl 999 \
  -t 8 \
  -c 65536 \
  -b 512 \
  -ub 1024 \
  --parallel 1 \
  -fa on \
  --jinja \
  --keep 1024 \
  --cache-type-k q8_0 \
  --cache-type-v q8_0 \
  --swa-full \
  --no-context-shift \
  --chat-template-kwargs '{"enable_thinking": false}' \
  --mlock \
  --no-mmap

# Verify model
$ curl http://localhost:8131/v1/models | jq .

# Install Claude Coe
$ brew install --cask claude-code
# Verify
$ claude --version
# Configure Claude
